Professional design portfolio website for **Aaim Studio by Maryam Afzal**, showcasing Graphic Design, YouTube AI Videos, UGC Commercial Ads, Social Media Marketing, and WhatsApp Automation.

6. **Ambient Theme Switcher**:
   - Seamless Dark Mode & Light Mode support matching Aaim Studio's brand logos.

## 🚀 How to Deploy on GitHub Pages (Free Hosting)

### Method 1: Using GitHub Actions (Recommended)

1. Create a new repository on your GitHub account (e.g. `aaim-studio-portfolio`).
2. Run these commands in your project folder:
   ```bash
   git init
   git add .
   git commit -m "feat: complete Aaim Studio design portfolio"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/aaim-studio-portfolio.git
   git push -u origin main
   ```
3. In your GitHub repository:
   - Go to **Settings** > **Pages**
   - Under **Build and deployment > Source**, select **GitHub Actions**
4. The workflow in `.github/workflows/deploy.yml` will automatically build and publish your portfolio at `https://YOUR_USERNAME.github.io/aaim-studio-portfolio/`!
